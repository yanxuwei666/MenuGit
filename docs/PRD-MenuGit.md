## 1. 产品目标

MenuGit 是一款面向个人开发者的 macOS Git 工具。用户在 Finder 中右键文件、文件夹或文件夹空白区域，从 MenuGit 菜单进入常用操作；界面借鉴 TortoiseGit 的操作方式，并适配 macOS。

首版只考虑 macOS，目标支持 Apple Silicon 和 Intel。Finder 覆盖范围、最低系统版本和具体兼容矩阵需经过真实环境验证，不能根据原型推定。

## 2. 首版范围

| 场景 | 首版功能 |
| --- | --- |
| Finder 入口 | 仓库文件或目录右键；非仓库目录右键创建或克隆；多选文件进入提交或日志上下文。 |
| 日常操作 | 查看文件状态和差异、提交、推送、拉取、创建和切换分支、查看日志。 |
| 冲突处理 | 拉取或合并遇到冲突后，逐块或批量选择内容，手动编辑合并结果，解决后继续或确认中止。 |
| 应用支持 | Finder 扩展启用指引；Dock 启动兜底、最近仓库、诊断、关于和手动检查更新。 |

首版不做其他平台、状态角标、一键放弃修改、强制推送、stash 界面、交互式 rebase、标签管理、行级暂存、子模块管理、分支重命名或删除、历史分支图和图片差异。完整边界见[需求规格第 2 节](Requirements-Spec-MenuGit-macOS.md#2-首发范围)。

## 3. 核心流程

1. 在仓库或其内部路径右键，选择“提交、推送、拉取、分支、日志、设置”中的操作；非仓库目录提供创建、克隆及设置。
2. 提交窗口显示选择范围、文件状态、差异和提交信息。提交只创建本地提交；成功后显示独立的推送确认窗口，用户可推送或稍后推送。
3. 推送被拒时保留本地提交，提供拉取入口；拉取按用户的 Git 策略处理，产生冲突时进入冲突处理。
4. 冲突窗口左侧选择文件，右侧查看和处理冲突块；解决所有文件后，用户选择继续当前合并或变基，完成后可再次确认推送。
5. 未配置远端时，推送流程允许用户添加仅属于当前仓库的远端地址；原型需要同步该决定。

不增加独立“冲突”菜单项。冲突处理中关闭窗口后，可通过相关仓库操作返回处理现场。Finder 发起的操作直接打开对应窗口，Dock 启动提供兜底入口；兜底界面尚未在原型展示。

## 4. 技术与交付方向

当前技术方向是 SwiftUI / Swift 主应用、Finder Sync 扩展和系统 Git。计划通过签名、公证的 DMG 分发；依赖真实环境验证 Finder 扩展覆盖、访问权限、Git 认证、hooks、冲突处理和 Universal 构建。该方向不表示已经实现或通过验收。

## 5. 基线与待确认事项

详细功能、验收边界和待确认事项均以[需求规格](Requirements-Spec-MenuGit-macOS.md)为准。当前仍需确认：

- **D-01：**选中文件提交其当前工作区完整内容，并提示包含未暂存修改；未选文件的暂存内容保留。
- **D-02：**推送流程允许添加当前仓库的远端地址。
- **D-03：**冲突草稿同次运行内保留；正常退出时提示保存或放弃，意外退出可能丢失。
- **T 项：**Finder 覆盖及权限、最低系统版本、Intel 构建与验收，以及真实 Git 行为等技术验证。

原型是使用模拟数据的交互演示；它的成功提示和进度不代表真实 Git 操作已经执行。旧版 PRD 只用于查阅历史，不再定义当前首版范围。
